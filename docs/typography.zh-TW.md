# 字型視覺觀察

[English](typography.md) | 繁體中文（台灣）

小尺寸點陣文字的效果，不只取決於標示的字級。比較時應觀察固定字框內實際可見的
筆畫範圍，以及文字和周圍標籤、邊框的相對關係。

## 明體與黑體家族

明體的粗細筆畫差異可能較明顯。在小尺寸點陣化後，細筆畫可能變淡甚至消失，
但其字形比例可能適合傳統風格的畫面。黑體的筆畫通常較均勻；不過字重過重時，
仍可能讓字內留白封閉，或使相鄰筆畫黏在一起。這些只是常見傾向，不是對兩個
字型家族內所有字型的優劣排名。

比較時，應固定文字內容、字框尺寸、前景、背景與繪製條件，再觀察：

- 實際可見的高度與寬度，而不只看設定的點數或像素尺寸。
- 筆畫密集的字是否仍可辨識，字內留白是否保留。
- 基線對齊、標點位置與字距。
- 在實際背景上的對比與可讀性。
- 與相鄰標籤及原本占用版面範圍的平衡。

即使設定相同字級，副標看起來仍可能較小。適度調整尺寸或位置可能改善平衡，
但須確認是否裁切，以及資源配置空間是否足夠。將完成的點陣圖片放大，只會改變
呈現尺寸，不會增加原始字形點陣的細節。

本文只討論字型家族層級的視覺特性，不列出特定廠商或已安裝字型的詳細名稱，
也不包含字型檔、可重用的字形點陣或遊戲截圖。實際字型轉換、嵌入與重新散布的
權限，須依所選字型的授權條款判斷；視覺觀察本身不會提供這些權限。
